Lesson 31: Conditional Mood (Feltételes mód)

Learn to express wishes, polite requests, and hypothetical situations using the Hungarian conditional mood with endings like -nék/-nám and the essential "szeretnék" (I would like).

Learning Objectives

  • Form conditional mood with -né-/-ná- marker
  • Distinguish indefinite (-nék) vs definite (-nám) conditional endings
  • Use "szeretnék" (I would like) for polite requests
  • Express hypothetical situations and wishes
  • Make polite requests in everyday situations

Section 1: What is the Conditional Mood?

The conditional mood in Hungarian is used for:

  • Wishes: Szeretnék egy kávét. (I would like a coffee.)
  • Polite requests: Megmondaná az időt? (Would you tell me the time?)
  • Hypothetical situations: Ha gazdag lennék... (If I were rich...)
  • Softened statements: Azt mondanám, hogy... (I would say that...)

Present Indicative:

Kávét kérek.

I want a coffee. (direct)

Conditional (polite):

Kávét kérnék.

I would like a coffee. (polite)

Section 2: Conditional Endings - Indefinite Conjugation

The conditional marker is -né-/-ná- (following vowel harmony), placed between the verb stem and the personal ending.

Pronoun Ending (back vowel) Ending (front vowel) Example: vár (wait) Example: kér (ask)
én-nék-nékvárnékkérnék
te-nál-nélvárnálkérnél
ő/Ön-na-nevárnakérne
mi-nánk-nénkvárnánkkérnénk
ti-nátok-nétekvárnátokkérnétek
ők/Önök-nának-nénekvárnánakkérnének

Note: The first person singular always ends in -nék regardless of vowel harmony. This is a special exception!

Section 3: Conditional Endings - Definite Conjugation

When the object is definite (the book, him, it, etc.), use the definite conditional endings:

Pronoun Ending (back vowel) Ending (front vowel) Example: lát (see) Example: néz (watch)
én-nám-némlátnámnézném
te-nád-nédlátnádnéznéd
ő/Ön-ná-nélátnánézné
mi-nánk-nénklátnánknéznénk
ti-nátok-néteklátnátoknéznétek
ők/Önök-nák-néklátnáknéznék

Indefinite (no specific object):

Olvasnék valamit.

I would read something.

Definite (specific object):

Olvasnám a könyvet.

I would read the book.

Section 4: "Szeretnék" - I Would Like

Szeretnék = I would like

This is one of the most useful phrases in Hungarian! It comes from "szeret" (to love/like) in the conditional mood.

Pronoun Conditional of "szeret" Translation
énszeretnékI would like
teszeretnélyou would like
ő/Önszeretnehe/she/you (formal) would like
miszeretnénkwe would like
tiszeretnétekyou (pl) would like
ők/Önökszeretnénekthey/you (formal pl) would like

Common Uses of "szeretnék":

Szeretnék egy kávét.

I would like a coffee.

Szeretnék fizetni.

I would like to pay.

Szeretném látni a menüt.

I would like to see the menu.

Szeretnénk foglalni.

We would like to make a reservation.

Note the difference:

  • Szeretnék + noun/indefinite = I would like (something)
  • Szeretném + definite object = I would like (the specific thing)
  • Szeretnék + infinitive = I would like to (do something)

Section 5: Polite Requests with Conditional

The conditional mood makes requests much more polite in Hungarian. Here are common patterns:

Direct (Less Polite) Conditional (Polite) Translation
Kérek egy vizet.Kérnék egy vizet.I would like a water.
Segít nekem?Segítene nekem?Would you help me?
Megmondja az időt?Megmondaná az időt?Would you tell me the time?
Adsz egy tollat?Adnál egy tollat?Would you give me a pen?
Elmondja még egyszer?Elmondaná még egyszer?Would you say it again?

Useful Polite Phrases:

Megkérhetném...?

Could I ask you to...?

Lenne szíves...?

Would you be so kind as to...?

Megtenné, hogy...?

Would you do (the favor of)...?

Tudna segíteni?

Could you help?

Section 6: Conditional of "lenni" (to be)

The verb "lenni" (to be) has an irregular conditional form that is very important for hypothetical sentences:

Pronoun Conditional Translation Example
énlennékI would beBoldog lennék. (I would be happy.)
telennélyou would beGazdag lennél. (You would be rich.)
ő/Önlennehe/she would beJó lenne. (It would be good.)
milennénkwe would beOtt lennénk. (We would be there.)
tilennétekyou would beEgyütt lennétek. (You would be together.)
őklennénekthey would beBoldogok lennének. (They would be happy.)

Common expressions with "lenne":

  • Jó lenne = It would be good
  • Lehetne = It could be / Could it be possible
  • Kellene = It would be necessary / should

Lesson Summary

Key Points:

  • Conditional marker: -né-/-ná-
  • First person singular always: -nék
  • Szeretnék = I would like (very common!)
  • Use conditional for polite requests
  • Lenne = would be (from lenni)

Essential Phrases:

  • Szeretnék egy kávét. (I'd like a coffee.)
  • Segítene? (Would you help?)
  • Jó lenne. (It would be good.)
  • Tudna segíteni? (Could you help?)
