# Hungarian Language Curriculum Plan

## Expert Pedagogical Framework

### About This Curriculum

This curriculum is designed by applying polyglot methodology and second language acquisition (SLA) research to Hungarian - one of the most challenging languages for English speakers. Hungarian belongs to the Uralic language family (Finno-Ugric branch), making it linguistically distant from Indo-European languages like English, Spanish, or German.

### Core Expertise Applied

**Polyglot Methodology:**
- Comprehensible Input (Krashen's i+1 theory)
- Spaced Repetition Systems (SRS) through revisitable lesson units
- Active Recall over passive recognition
- Contextual learning through realistic scenarios
- Phoneme-first approach for tonal accuracy

**Hungarian-Specific Considerations:**
1. **Agglutinative Structure** - Hungarian builds meaning through suffix chains (unlike English prepositions)
2. **Vowel Harmony** - Critical grammatical rule affecting all suffixes
3. **Definite/Indefinite Conjugation** - Unique verb system based on object specificity
4. **18 Grammatical Cases** - Expressed through suffixes, not word order
5. **Topic-Focus Word Order** - Flexible but meaning-laden sentence structure
6. **No Grammatical Gender** - One advantage for English speakers!

### Learning Principles

| Principle | Implementation |
|-----------|----------------|
| **Scaffolded Progression** | Each lesson builds on prior knowledge |
| **Multi-Modal Learning** | Visual, auditory cues, and kinesthetic interaction |
| **Error-Aware Feedback** | Distinguishes between wrong answer, accent errors, and correct |
| **Spaced Repetition** | Modular lessons can be retaken for reinforcement |
| **Contextual Application** | Real-world dialogues and scenarios |
| **Active Production** | Fill-in-blank, transformation, free response exercises |
| **Immediate Assessment** | Score tracking motivates completion |

## Curriculum Structure

The curriculum follows the **CEFR (Common European Framework of Reference)** levels:
- **A1 (Weeks 1-12):** Breakthrough - Basic phrases, introductions, simple questions
- **A2 (Weeks 13-26):** Waystage - Everyday expressions, simple descriptions, routine tasks
- **B1 (Weeks 27-40):** Threshold - Main points on familiar matters, travel, experiences
- **B2 (Weeks 41-52):** Vantage - Complex texts, spontaneous interaction, detailed expression

Each week contains **one primary lesson** that can be:
- Completed independently (modular design)
- Mixed with other lessons for variety
- Retaken for reinforcement
- Used as reference material

## Interactive Exercise Types

Each lesson incorporates multiple exercise types for kinesthetic and active learning:

### Exercise Type Reference

| Type | Description | JavaScript Pattern | Best For |
|------|-------------|-------------------|----------|
| **Fill-in-Blank** | Complete missing word(s) | Input + Enter key validation | Grammar patterns, conjugation |
| **Multiple Choice** | Select correct option | Radio/button selection | Recognition, quick assessment |
| **Dropdown Selection** | Choose from options | Select element + change event | Binary choices, case selection |
| **Card Flip** | Click to reveal answer | State cycling on click | Vocabulary, definitions |
| **Drag & Drop** | Match items | Draggable elements | Matching, ordering |
| **Sentence Building** | Arrange words | Sortable word tiles | Word order practice |
| **Transformation** | Convert sentence form | Free input comparison | Tense/case changes |
| **Dialogue Completion** | Fill conversation gaps | Sequential inputs | Practical application |
| **Listening Comprehension** | Answer based on audio | Audio element + questions | Pronunciation, comprehension |
| **Writing Production** | Free-form response | Textarea + model answer | Advanced production |
